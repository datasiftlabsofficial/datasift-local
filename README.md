# DataSift Local 🚀

Un procesador y limpiador de archivos CSV y JSON ultrarrápido que opera **100% en el lado del cliente (client-side)** dentro de tu navegador. Diseñado para garantizar la privacidad absoluta de los datos corporativos y personales sin depender de servidores de terceros.

---

## 🔒 ¿Por qué DataSift Local?

La mayoría de las herramientas de limpieza y conversión de datos en la web obligan a subir tus ficheros a servidores externos. Si manejas datos sensibles, de clientes o información interna, esto infringe normativas de privacidad. 

**DataSift Local** procesa todo utilizando la memoria y el motor de tu propio navegador mediante JavaScript puro y PapaParse. Tus archivos **nunca abandonan tu equipo**.

---

## ⚡ Características Principales

*   📁 **Carga Instantánea (Drag & Drop):** Soporte para ficheros CSV y JSON.
*   🧹 **Herramientas de Limpieza Esenciales:**
    *   *Trim de espacios:* Elimina espacios en blanco invisibles al inicio y final.
    *   *Purgado de vacíos:* Remueve filas incompletas o nulas.
    *   *Eliminación de duplicados:* Limpia registros repetidos con un solo clic.
    *   *Buscar y Reemplazar:* Modifica términos de forma global en todo el set de datos.
*   💻 **Cero Dependencias de Servidor:** Funciona de forma totalmente estática.
